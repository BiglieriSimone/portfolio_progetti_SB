## Progetti Principali

### [Gestione Centro - Progetto Java]
* **Descrizione:** Applicazione per la gestione di un centro (es. sportivo, medico, logistico) sviluppata in Java applicando i principi dell'Object-Oriented Programming (OOP).
* **Tecnologie:** Java, Swing, JUnit
* **Punti chiave:**
  * Implementazione di ereditarietà, polimorfismo e incapsulamento.
  * Gestione della persistenza dati o file I/O.
  * Test unitari per verificare controlli di consistenza dei dati.
* 🔗 **[Guarda il codice completo su GitHub](https://github.com/BiglieriSimone/gestioneCentro_Java)**

### [Database & Progettazione Schema ER - Progetto Basi di Dati (in team)]
* **Descrizione:** Progettazione concettuale e logica di un database relazionale, con successiva implementazione su PostgreSQL e stesura della documentazione tecnica.
* **Tecnologie:** PostgreSQL, SQL, Modellazione ER (Entity-Relationship).
* **Punti chiave:**
  * Modello Concettuale (Schema ER) e ristrutturazione per la traduzione nel modello Logico.
  * Definizione dello schema DDL e query DML.
  * Relazione tecnica completa a supporto delle scelte architetturali.
* 🔗 **[Guarda la repository e la documentazione su GitHub](https://github.com/BiglieriSimone/nutriCare_BDD)**
